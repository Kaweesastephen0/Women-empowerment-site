# Women Empowerment Site

This repository contains a professional, standalone static website for a Women Empowerment Initiative. It includes HTML, CSS, and JavaScript pages you can open locally or deploy to any static hosting service.

Quick start
1. Open `index.html` in a browser to preview the site.
2. Or serve the folder with a simple static server, for example:

```bash
# Python 3
python3 -m http.server 8000

# Node (http-server)
npx http-server -p 8000
```

Files created
- `index.html`, `about.html`, `programs.html`, `resources.html`, `events.html`, `donate.html`, `contact.html`
- `css/styles.css` — global styles
- `js/script.js` — simple interactivity and form handling
- `Logo1.jpeg` — placeholder logo (now used site-wide)
